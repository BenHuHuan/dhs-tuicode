# Agent Note: 手动 TUI 工作区检查点与回退

Status: implemented

[English](2026-08-15-tui-workspace-checkpoints.md) | 中文

## Problem

终端此前能够查看对话并恢复持久会话，却没有把可读的工作区状态与安全对话边界绑定在一起的明确恢复点。仅有原始 `git diff` 不够：用户需要保存已暂存改动、未暂存改动和新建文件，同时不能把这些内容放进模型上下文。就地回退还会丢弃原会话，或可能让子会话种子包含未闭合的命令或轮次生命周期。

## Decision

`@deepseek-ai/dsh-tui` 定义宿主侧的 `WorkspaceHistory` 边界，并提供 `LocalWorkspaceHistory`。它把检查点元数据和文件保存到项目工作树之外的 `DSH_HOME/workspace-checkpoints/v1/<sha256(session-id)>`。Git 检查点记录解析后的 Git 根目录、会话目录作用域、`HEAD`、已暂存补丁、未暂存补丁，以及未被忽略的未跟踪普通文件或符号链接。非 Git 目录也会得到持久的仅对话检查点，并记录不可用原因。

`/diff` 会为当前受作用域限制的 Git 改动集打开只读全屏分页器。`/checkpoint [label]` 保存其自身待处理 `command/run` 记录之前的事件边界，因此后续子会话种子绝不会包含悬空命令生命周期。`/rewind [checkpoint-id]` 会选择已保存的检查点，随后分别询问恢复工作区、分支对话或两者，并要求显式输入 `y` 确认。

工作区恢复会先把当前状态保存为可见的安全检查点。它拒绝已变化的 Git 根目录、会话目录或 `HEAD`；只移除已捕获作用域内当前未被忽略的未跟踪路径；从记录的提交恢复受跟踪路径；随后重新应用已暂存和工作树补丁以及检查点中的未跟踪文件。空补丁文件会被有意跳过，因为 `git apply` 会拒绝它们。快照 diff 会禁用重命名检测，因此从嵌套会话目录创建的检查点不会携带该目录之外的重命名端点。安全检查点持久化后，恢复和安全回退使用不可取消的操作信号：预检阶段仍可取消，但已确认的文件系统恢复不会停在半完成状态。

对话回退使用 runner 的精确已完成事件边界创建具有新身份的子会话，并写入 `parentSession` 与 `seedLength` 元数据。源会话绝不会被截断，仍可恢复。当组合回退已经恢复文件、但之后子会话交换失败时，新的安全检查点仍可供用户显式恢复。

## Alternatives considered

**就地截断会话并使用 `git reset --hard`。** 未采用，因为二者都会丢弃原始恢复路径，也太容易造成意外数据丢失。所选检查点必须分支对话历史并保留独立的安全检查点。

**每次编辑或工具调用后自动创建快照。** 未采用，因为 TUI 不拥有每一次文件系统修改，文件量将不受界限，而且自动快照会模糊用户选定的恢复边界。检查点保持显式创建。

**基于提交恢复或跨提交应用补丁。** 未采用，因为后续提交可能改变补丁的可应用性和语义。提供方要求解析后的根目录、目录作用域和 `HEAD` 相同，而不是把检查点伪装成通用 Git 历史改写。

**把 diff 或检查点内容展示给 agent。** 未采用，因为检查和恢复是本地用户操作。TUI 只在终端 overlay 中渲染这些文件，不会把任何工作区字节加入模型上下文。

## Consequences

终端用户无需图形客户端即可获得可恢复、可审阅的编码循环：用 `/diff` 检查、用 `/checkpoint` 命名一个点，再用 `/rewind` 精确选择要恢复的状态。该能力有意保持手动、受 Git 作用域限制且需要单宿主协调：不会提供被忽略文件、每次编辑的自动快照、跨提交恢复、自动创建 worktree，或原子化的文件系统加会话交换。

分支不变量遵循已有的 [SessionStore fork API](2026-06-30-session-store-fork-api.md) 和[已完成轮次尾部规则](../bug-fix/2026-08-02-message-fork-actions-require-completed-turn-tail.md)：子会话回放从平衡的持久前缀开始，原始日志仍是权威且可恢复的记录。

## Verification

聚焦的 Git 集成测试覆盖已暂存、未暂存、未跟踪、被忽略、空补丁、嵌套目录重命名、相同 `HEAD`、非 Git 目录，以及安全检查点创建后的取消行为。runner 测试固定精确种子选择，并拒绝活动轮次边界。已挂载的 TUI 测试和无密钥快照覆盖 diff 分页器、检查点命令、动作选择器、显式确认和子会话交换交接。
