# Agent Note: TUI 对话导出

Status: implemented

[English](2026-08-15-tui-conversation-export.md) | 中文

## Problem

持久会话可以恢复，但终端没有专门命令来分享它完整且可读的记录。`/copy` 有意只选择一条 assistant 回复或代码块，因此无法把用户提示词、注入上下文、工具流量和被中断轮次一起保留下来。导出必须由人类主动发起，且不能把本地归档操作变成模型输入。

## Decision

`@deepseek-ai/dsh-tui` 注册 `/export [filename]`。它把当前会话 header 与按时间顺序的持久事件渲染为纯文本：用户和注入上下文消息、已结算的 assistant 消息、工具调用、工具结果，以及每个未完成轮次的简洁标记。原始流式 chunk 和请求记账信息会被省略，因为它们不是可读的 transcript。

提供文件名时，命令写入所选路径。不提供时，overlay 提供复制到剪贴板或保存到相对文件 `dsh-session-<session-id>.txt`。两种目标都使用既有、可取消的宿主 writer。文件创建采用独占方式，已有路径需要与 `/copy` 相同的显式覆盖确认；传输内容时会禁用重复提交，直到宿主调用结算。

该命令读取持久日志，不会追加事件、steer 根 agent，也不会把导出文本或目标路径交付给模型。它复用 TUI 的终端本地剪贴板与文件 writer 集成，二者仍属于用户信任的部署 helper。

## Verification

`export.spec.ts` 固定文件名清理、按时间顺序的可读渲染、来源标签、工具调用／结果关联、未完成轮次标记，以及已完成轮次记账信息的省略。已挂载的 `tui.spec.ts` 覆盖带引号的显式路径、受保护的覆盖确认、不带参数的复制／保存选择、不可用宿主，以及根 agent 没有收到消息。无密钥的真实 TUI snapshot 固定选择器和 `/help` 清单。

## Alternatives considered

**导出可见终端缓冲区。** 未采用，因为终端换行、ANSI 样式、卡片折叠和滚动缓冲区不能构成稳定或完整的对话记录。

**立即写入默认文件。** 未采用，因为不带参数的命令必须让用户在剪贴板和磁盘之间选择，并且不应在未明确选择目标时创建文件。

**通过 agent 发送导出内容。** 未采用，因为本地分享操作不需要推理，并可能把敏感对话数据加入模型上下文。

## Consequences

终端用户可以在不离开 TUI、也不需要图形客户端的情况下保存或分享完整且可读的会话。输出有意是供人阅读的记录而非回放格式；精确重建仍以会话持久化为准。剪贴板和文件目标会接收明文会话内容，因此部署仍必须信任其配置的 helper。
